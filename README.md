用手机浏览器打开。首页输入订单号后开始：到小红书「我的订单」复制，每个订单号可以测 3 次。18 道原创中文情景题，五级自评（完全不像我 → 非常像我），六个权谋、六个自恋、六个冷酷。结果给出暗面指数、等级、主导类型、三维雷达、特征表现和改善建议。

## 订单号

订单号在页面上核对格式。格式通过后立刻开始答题。页面不为订单号请求 `*.vercel.app`，也不读写 Mantle 的 `orders/`。

| 项 | 值 |
|---|---|
| 格式 | 只接受 `P` + 18 位。重复块和逐位 ±1 的序列提示「订单号格式不对」，19 位也不接受，并且不会开始答题 |
| 通过 | 立刻解锁并开始。没有订单绑定、没有限流、没有服务器次数 |
| 显示 | 第一次开始提示「验证成功，还可以测 2 次」。再测一次后是「还可以测 1 次」，然后「验证成功，这是最后一次」 |
| 不改显示 | 刷新、继续这一次、结果恢复、查看上次结果 |
| 三次之后 | 同一个订单号仍可进入，提示「验证成功」 |

## 已发出的访问码

已经发出的访问码仍走真实核销：先 `POST /redeem`，body `{ "quiz": "dark", "code" }`。vault 明确用尽则不再落到 Mantle。vault 没有这枚码时才回退本测验的 Mantle `dt/`，按那里的剩余次数扣 1 次。同一标签页里点「再测一次」会清掉本次解锁，再次提交才扣 1 次。刷新页面和「查看上次结果」不扣次。
