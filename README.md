# 黑暗人格三角测试

娱乐向自我探索 · 你敢面对真实的自己吗

线上地址：<https://zengpenghui420-glitch.github.io/dark-triad/>

用手机浏览器打开。首页输入订单号后开始：到小红书「我的订单」复制，每个订单号可以测 3 次。18 道原创中文情景题，五级自评（完全不像我 → 非常像我），六个权谋、六个自恋、六个冷酷。结果给出暗面指数、等级、主导类型、三维雷达、特征表现和改善建议。

本测试为娱乐向自我探索，题目为原创情景改编，不构成心理诊断、人格障碍评估或任何医学建议。高分只代表自我报告倾向偏强，不代表道德好坏。

## 订单号

| 项 | 值 |
|---|---|
| 核销 | `POST /order/redeem`，body `{ "quiz": "dark", "orderId" }` |
| 只读 | `GET /order/get?quiz=dark&orderId=`，不扣次数、不绑定 |
| 次数 | 一笔订单只绑定本测试，最多 3 次 |
| 答题中 / 结果刷新 | 只 peek，不扣次 |
| 再测一次 | 再核销 1 次；随后点「开始测试」不再扣 |
| 查看上次结果 | 只读本机记录，不扣次 |

已发出的访问码仍走本页原来的 Mantle `dt/` 读写，不改走 `/redeem`。同一标签页里点「再测一次」会清掉本次解锁，再次提交才扣 1 次。刷新页面和「查看上次结果」不扣次。
